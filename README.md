# HomeCast

Shanghai Telecom IPTV playlists and programme guides for a trusted home LAN.

The initial implementation is under development on a feature branch. This
repository does not include subscriber identities, packet captures or a channel
subscription. Support is limited to Shanghai Telecom with an existing, working
IPTV network.

Licensed under MIT. Reviewed pull requests and passing CI are required before
release. Published images will be available through GitHub Container Registry.
